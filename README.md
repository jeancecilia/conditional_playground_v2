# Behandlungs-Einwilligung (Android)

Einfache Offline-App für eine schriftliche Einwilligung vor Anamnese/Behandlung im Rahmen einer Heilpraktikererlaubnis, beschränkt auf das Gebiet der Psychotherapie.

## Funktionen
- Behandler/in editierbar
- Patientenname
- kurzer Einwilligungstext
- zwei Pflichtbestätigungen
- Unterschrift direkt mit dem Finger
- lokale PDF-Erzeugung im privaten App-Speicher
- PDF per Android-Teilen-Menü exportierbar
- keine Internetberechtigung

## Build
`gradle :app:assembleDebug`

Hinweis: Der Text ist eine praktische Vorlage und keine individuelle Rechtsberatung. Die App ersetzt nicht die erforderliche individuelle Aufklärung.
